# 格式转换器 - 项目架构规划

## 一、技术栈

| 组件 | 技术选型 |
|------|---------|
| 语言 | Python 3.10+ |
| GUI（可选） | PyQt5 / Tkinter / Gradio |
| PDF解析 | PyMuPDF (fitz) / pdfminer.six |
| DOCX处理 | python-docx |
| DOC处理 | antiword / pywin32 |
| MD转换 | markdown / mistune |
| MD→PDF | weasyprint / pandoc |
| MD→DOCX | python-docx |

## 二、支持格式矩阵

```
输入格式 → 输出格式
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
PDF   → MD
DOCX  → MD
DOC   → MD
TXT   → MD

MD    → PDF
MD    → DOCX
```

```

```

## 四、转换器基类设计

```python
class BaseConverter:
    def convert(self, input_path, output_path) -> bool

```

## 五、CLI 界面设计

```bash
# 单文件转换
python -m converter convert input.pdf output.md
python -m converter convert input.md output.pdf

# 批量转换
python -m converter batch "*.pdf" ./output/

# GUI 模式
python -m converter gui
```

## 八、已知难点

1. **PDF转MD**：PDF语义结构（标题/列表/表格）识别困难，保留格式更难
2. **DOC转MD**：需要 antiword 或 LibreOffice 辅助
3. **MD转PDF**：中文渲染、字体嵌入、样式保持
4. **格式保留**：图片、表格、超链接的跨格式保留
